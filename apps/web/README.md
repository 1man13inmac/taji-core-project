# Web App (Taji Core Project)

This Next.js app contains the primary PWA pages and navigation for:
- lineages
- teachers
- family tree
- timeline
- techniques
- history
- philosophy
- source standards
- admin/user areas (scaffolding)

## Local Run

```bash
corepack enable
corepack pnpm install
corepack pnpm --filter web dev
```

## Build

```bash
corepack pnpm --filter web build
```

## Lint

```bash
corepack pnpm --filter web lint
```
